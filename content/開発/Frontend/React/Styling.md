# Styling

## Library

### TailwindCss

### [Class Variance Authority](https://cva.style/docs)

Headless componentとして作り、コンポーネントのスタイルと機能を分けて作ることを心がけたい。
## Tips

Component内で完結するようなスタイルを心がける。例えばComponent内のCssでPaddingの設定はしてもMarginの設定しない。レイアウトに関するStyleは利用側に設定してもらう、しやすい形を意識して作ると良い。
