# Programming with MoonBit A Modern Approach

序盤だけやってみたところ、これは式志向プログラミングスタイル(expression-oriented programming)のTDDでの行い方を学ぶためのチュートリアルだった。このスタイルは特殊なものではなくOCamlやRustで行われている一般的な考え方なはず。Moonbitの開発自体がOCamlで行われているのでその影響を感じる。

1~6章までは 11~14章が実践的な内容になっていて、パーサーやスタックマシンなどコンパイラを作るのに必要な知識が学べる。
