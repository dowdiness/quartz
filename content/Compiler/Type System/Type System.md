## Curry-style と Church-style

Curry-styleでは既に存在する項に対してextrinsicな型付けを行い、Church-styleでは型付けされた項しか存在できない、つまりintrinsicな型付けが行われる。

https://www.cannorin.net/blog/2018-07-07-difference
