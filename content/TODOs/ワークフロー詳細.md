# ワークフロー詳細

タスク管理システムの朝・日中・夜のワークフローを詳しく解説します。

---

## 🌅 朝のルーチン（5分）

### 1. デイリーノートを開く
- Obsidianで今日の日付のノートを作成
- テンプレート: `02_daily-enhanced.md` を使用
- ショートカット: Templaterで自動化可能

### 2. 「朝」セクションに記入

```markdown
## 🌅 朝

**昨日の反省:**
- （前日のデイリーノートから振り返り）

**今日の予定（外部）:**
- [ ] 通院 14:00
- [ ] ゴミ出し

**やりたいこと:**（[[Tasks]]から1-3個選ぶ）
- タスクA
- タスクB

**体調:** 3/5
（午前中は低調、午後から回復予定）
```

### 3. AIアシスタントを開く
- **Claude Desktop**: MCPで直接連携
- **ChatGPT**: Custom Framesで右側に表示
- **Gemini CLI**: ターミナルから起動
- 新しい会話を開始

### 4. AIに情報を共有
1. [[AI秘書プロンプト]] の内容をコピペ
2. デイリーノートの「朝」セクションをコピペ
3. AIの返答を待つ

### 5. AIの提案を聞く
AIが以下を提案してくれます：
- 現実的なスケジュール（1-3タスク）
- 体調を考慮した計画
- 固定予定を優先した時間配分
- 中期目標に沿うタスクの提案

### 6. 今日を始める
提案を参考に、やりたいことから始める

---

## 💼 日中のワークフロー

### タスクを始めるとき

**基本の報告:**
```
〇〇を開始します。時刻は12:30
```

**AIの対応:**
- 開始時刻を記録
- 必要に応じて休憩のリマインド
- 集中できる環境を応援

### 休憩・終了するとき

**基本の報告:**
```
〇〇を終了します。時刻は13:00
```

**AIの対応:**
- 作業時間を計算
- 進捗点を記録（+1〜+3）
- 中期目標ボーナスがあれば適用
- 次の提案（必要なら）

### 進捗点の計算ルール

| 作業時間 | 進捗点 | 備考 |
|---------|-------|------|
| 15-30分 | +1 | 短時間の集中作業 |
| 30-60分 | +2 | 標準的な作業時間 |
| 60-90分 | +3 | 長時間の集中 |
| 90分以上 | 30分ごとに+1 | 適度な休憩を推奨 |

**中期目標ボーナス:**
- 中期目標に沿う作業: x2 や x3
- 例: 1時間作業 → +2 → x2 = +4

### 思いついたこと

**すぐメモする:**
```markdown
## 💭 メモ

- プログラムのバグ発見、後で調査
- 新しいタスクのアイデア
- 気になったこと
```

**AIに壁打ち:**
- 悩みや疑問を共有
- アイデアの整理を手伝ってもらう
- 具体的な解決策を提案してもらう

### ルールを守る

#### ✅ やること
- やりたいことをやる
- AIに報告する
- メモを取る
- 適度に休憩

#### ❌ やらないこと
- 締め切りを気にする
- 優先順位で悩む
- 完璧を目指す
- 無理をする

## 🌙 夜のルーチン（10分）

### 1. 21:00に終業

**重要:**
- それ以降の作業は進捗点に入れない
- 意識的に休息する時間
- 深夜作業は「メモ」に記録するだけ

**AIへの報告:**
```
今日は終業します
```

### 2. AIに「まとめ」と言う

**AIの出力形式:**
```markdown
**稼働開始:** 12:30

- 12:30 ~ 13:00 タスクA +2
- 14:00 ~ 15:30 タスクB +3 (中期目標 x2)
- 16:00 ~ 17:00 タスクC +2

**合計進捗:** +10
**総稼働:** 3h30m

**終業:** 21:00
```

### 3. まとめをコピペ

デイリーノートの「作業記録」セクションにコピペ

### 4. 振り返り

**AIとの対話:**
- 今日の成果は？
- 改善できることは？
- 明日に向けて準備することは？
- 攻守のバランスは？

**振り返りの形式:**
```markdown
## 🌙 振り返り

**今日の成果:**
- タスクAを完了
- タスクBを50%進めた
- 新しいアイデアが浮かんだ

**改善点:**
- 午後の休憩をもっと取れば良かった
- メモが散らかっている

**明日への布石:**
- タスクBの続きから始める
- メモを整理する時間を取る

**攻守のバランス:**
- 防性の作業: 食事、休憩、散歩
- 攻性の作業: 3h30m、中期目標に貢献
```

### 5. おやすみ

振り返りをデイリーノートにコピペして完了

## ⏰ 日付の扱いについて

### 重要なルール

**寝るまでは同じ日として管理する**

例:
```
1月24日（土）
10:00 起床 → 24日のノートを作成
12:00-21:00 作業 → 24日のノートに記録
21:00 終業
23:00-01:30 趣味、リラックス → 24日のノートの「💭 メモ」に記録
02:00 就寝

1月25日（日）
11:00 起床 → ここで初めて25日のノートを作成
```

### 理由
- 生活リズムを自然な単位で区切るため
- 「起床から就寝まで」を1日として管理
- 深夜の活動を翌日扱いすると、振り返りが分断される

## 🔄 週次・月次（オプション）

### 週1回程度

**Tasksファイルの整理:**
1. 完了したタスクを「完了済み」に移動
2. 新しいタスクを追加
3. 上位16個を整理

### 月1回程度

**アーカイブ作業:**
1. 「完了済み」タスクをアーカイブ
2. 中期目標を見直す
3. システムの調整（必要なら）

---

## 💡 ポイント

- **朝は軽く**: 5分で完了する
- **日中は自然に**: 無理なく報告
- **夜は振り返り**: 10分で完了
- **21:00終業厳守**: 健康的な境界線
