現在はグループチャットでチームの話し合いを行っていますが、プライベートチームを作ってそこで必要なチャネルを作る形への移行は出来ないでしょうか？グループチャットではTeamsで使用できない機能が多くて不便だと思います。

```
今回のプロジェクト用のこういう形のチームとチャネルを作る

- 絵本制作チーム <- チーム
	- 一般 <- チャネル
	- シナリオ <- チャネル
	- アート・デザイン <- チャネル
	- ... 色々必要に合わせて <- チャネル
```

TeamsはSharePointというアプリに自動で連携されているので、これを使えばチャネル毎にアップデートされたファイルがドキュメントの確認や整理も出来ます。現在のネストラボ 通所メンバーのチャネルにアップロードされたファイルも下記のようにSharePointへとアップロードされて使用出来るようになっています。
