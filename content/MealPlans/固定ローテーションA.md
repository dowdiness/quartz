# 固定ローテーションA

夕食7品・昼食5品を各レシピの比率通りにまとめて作り、冷凍ストックから順に食べる。各レシピ内に材料比率を明記しているので、買った量に合わせて増減してよい。

## 買い物①

鮭・鶏むね・豚こまは夕食用と昼食用で分け合う。パックの実量をこの比率で切り分ければ端数が出ない。

- 鮭切り身: 夕食用:昼食用 = 3:2([[鮭とほうれん草のレンジ蒸し]] / [[鮭フレークと卵そぼろ]])
- 鶏むね肉: 夕食用:昼食用 = 3:5([[鶏むねとキャベツのレンジ蒸し]] / [[鶏むねの照り焼き風]])
- 豚こま肉: 夕食用:昼食用 = 2:3([[豚こまと小松菜の重ね蒸し]] / [[豚肉となすの味噌炒め]]+[[豚こまと根菜のきんぴら風]])

そのほかはレシピの比率通りに1パックずつ: キャベツ・小松菜・冷凍ほうれん草・厚揚げ・卵・なす・ごぼう・にんじん

作るもの: [[鮭とほうれん草のレンジ蒸し]] / [[鶏むねとキャベツのレンジ蒸し]] / [[豚こまと小松菜の重ね蒸し]] / [[厚揚げと卵の甘辛煮]] / [[鮭フレークと卵そぼろ]] / [[豚肉となすの味噌炒め]] / [[鶏むねの照り焼き風]] / [[豚こまと根菜のきんぴら風]]

## 買い物②

いずれも1品につき1パックで足りる比率にしてあるので、端数を気にせずパック単位で買えばよい。

- 厚揚げ1パック(2枚):しめじ1パック → [[厚揚げときのこのレンジ蒸し]]
- さば水煮缶1缶:木綿豆腐1丁 → [[さば缶と豆腐のレンジ煮]]
- 絹豆腐1丁:卵2個 → [[豆腐入り卵焼き]]
- ご飯:ツナ缶:卵 = 1:1:1(1人前セット) → [[ツナと卵のレンジチャーハン風]]

作るもの: [[厚揚げときのこのレンジ蒸し]] / [[さば缶と豆腐のレンジ煮]] / [[ツナと卵のレンジチャーハン風]] / [[豆腐入り卵焼き]]

## 常備品(切れたら買う)

- 米、めんつゆ、ポン酢、醤油、みりん、砂糖、塩、酒、ごま油、味噌、片栗粉、白ごま、おろし生姜、おろしにんにく

## 注意

- もやし・卵液の茶碗蒸しは冷凍に不向きなため、小松菜・卵焼きに変更済み(詳細は各レシピ参照)
- 木綿豆腐は冷凍すると食感が変わる([[さば缶と豆腐のレンジ煮]]参照)
